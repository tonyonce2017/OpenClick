## 中文

OpenClick 0.4.0 带来了中文界面，并可以在中英文之间即时切换。

### 新增

- **中英文界面**：首次运行跟随 Windows 显示语言，也可以在「设置 → 语言」中手动选择「跟随系统 / English / 简体中文」。
- **即时切换**：切换语言后当前窗口立即刷新文案并重新排版，无需重启。
- **设置持久化**：语言选择与其他设置一起保存在 `%APPDATA%\OpenClick\settings.json`。
- **中文字体**：中文界面使用 Microsoft YaHei UI，英文界面继续使用 Segoe UI。

### 下载

- `OpenClick-v0.4.0-win-x64.zip`：解压后直接运行 `OpenClick.exe`（自包含，无需安装 .NET 运行时）。
- 每个压缩包都附带 `.sha256` 校验文件，可用 `Get-FileHash` 或 `certutil -hashfile` 校验。

### 修复

- 「光标位置」面板与「停止」按钮此前会被窗口锚点推到可视区外，默认窗口下看不到；现在完整显示在「自动点击」标签页内。

### 说明

- 后台点击通过 `PostMessage` 发送，读取原始硬件输入的程序（例如部分游戏）可能忽略这些点击。
- 如需点击以管理员身份运行的程序，请以管理员身份运行 OpenClick。

## English

OpenClick 0.4.0 adds a Simplified Chinese interface and lets you switch between English and Chinese instantly.

### Added

- **English and Simplified Chinese UI**: the first run follows the Windows display language. Choose "Follow system / English / 简体中文" later under **Settings → Language**.
- **Live switching**: the open window re-applies its texts and reflows immediately, with no restart.
- **Persisted choice**: the selected language is stored with the other settings in `%APPDATA%\OpenClick\settings.json`.
- **Chinese font**: the Chinese UI uses Microsoft YaHei UI; English keeps Segoe UI.

### Download

- `OpenClick-v0.4.0-win-x64.zip`: extract and run `OpenClick.exe` (self-contained; no .NET runtime install needed).
- Every zip ships with a `.sha256` file; verify it with `Get-FileHash` or `certutil -hashfile`.

### Fixed

- The Cursor position panel and the Stop button were pushed outside the visible area by window anchoring and could not be seen in the default window; both now sit inside the Autoclick tab.

### Notes

- Background clicks use `PostMessage`, so programs that read raw hardware input (including some games) may ignore them.
- To click an application running as administrator, run OpenClick as administrator too.
