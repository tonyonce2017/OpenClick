## 中文

OpenClick 0.4.1 是一个界面修复版本，功能与 0.4.0 相同。

### 修复

- 中文界面下，「自动点击 → 光标位置 → 固定位置」的 X / Y 标签使用全角冒号，宽度大于英文标签，会盖住右侧数值输入框的左侧边缘。现在标签与输入框之间留出了足够间距，中英文界面都不再重叠。

### 下载

- `OpenClick-v0.4.1-win-x64.zip`：解压后直接运行 `OpenClick.exe`（自包含，无需安装 .NET 运行时）。
- 每个压缩包都附带 `.sha256` 校验文件，可用 `Get-FileHash` 或 `certutil -hashfile` 校验。

## English

OpenClick 0.4.1 is a UI fix release; behaviour is unchanged from 0.4.0.

### Fixed

- In the Chinese UI, the X / Y labels under Autoclick → Cursor position → Fixed use a full-width colon, making them wider than the English labels, so they covered the left edge of the number boxes. The labels and boxes now have enough spacing in both languages.

### Download

- `OpenClick-v0.4.1-win-x64.zip`: extract and run `OpenClick.exe` (self-contained; no .NET runtime install needed).
- Every zip ships with a `.sha256` file; verify it with `Get-FileHash` or `certutil -hashfile`.
